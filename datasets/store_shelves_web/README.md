# Магазинные полки из интернета: проверочный набор

Фото полок российских винных магазинов, найденные в интернете, и кадры 3:4 с вином
из каталога под центром кадра. **Только для проверки — не обучать на нём.**

**130 кадров, 101 исходное фото, 102 разных вина, 28 виноделен.** На каждом кадре
под центром — вино, которое есть в каталоге **в том же оформлении этикетки**.

`store_shelves_v1`/`v2` сняты в одном магазине и уходят в обучение через
`store_shelves_catalog`. Здесь — другие магазины, камеры, свет и годы съёмки:
сетевые супермаркеты (Магнит, Пятёрочка, Ашан, Дикси, Лента, «Да!» и др.),
фирменные магазины виноделен (Массандра, Инкерман, Абрау-Дюрсо, Золотая Балка,
Солнечная Долина, Фанагория…) и винотеки.

## Файлы

| Путь | Содержимое |
|---|---|
| `queries/w-001.jpg` … `queries/w-130.jpg` | Кадры 3:4, целевая этикетка под центром, соседи и ценники остаются в кадре. |
| `labels.csv` | Одна строка на кадр, те же поля, что в `store_shelves_v1`/`v2`; у всех `training_use = holdout`. |
| `source/web-001.jpg` … `source/web-101.jpg` | Исходные фото, до 4096 px по длинной стороне. |
| `points.csv` | Точка на этикетке и ширина бутылки (проценты от размеров фото), допустимые slugs, что видно на этикетке и ценнике. |
| `sources.csv` | Откуда каждое фото: сайт, страница, прямая ссылка на картинку, заголовок страницы, поисковый запрос, sha256 файла. |

## Как отбирали и размечали

1. Скачано 6 352 картинки; пакшоты интернет-магазинов и дубли отброшены.
2. Поиск бутылок каталога без нейросетей: RootSIFT по эталонам всех 2103 вин и
   проверка гомографией (RANSAC), как в `real_photos_v4`. Модель сканера (её YOLO и
   DINO) в отборе не участвовала, поэтому набор не подстроен под то, что она уже
   узнаёт. Стандартный COCO-детектор `yolo11n.pt` только отсеивал снимки, где меньше
   двух бутылок.
3. Глазами, в два прохода. Сначала «это полка магазина?»: домашние фото, бутылки
   на прилавке, в руке, в ящике, вывески и коробки отброшены. Затем каждый кадр рядом
   с эталоном: линейка, сорт, цвет, сладость, оформление этикетки; при сомнении —
   увеличенный фрагмент исходника и ценник. Проверено 228 кадров-кандидатов, принято 130.
4. Ответ ставился по этикетке, а не по SIFT: в 43 кадрах набора SIFT предложил
   соседнюю карточку той же серии (Портвейн белый Гурзуф вместо Алушты, Victor Dravigny
   брют вместо полусладкого, Губернаторское Ркацители вместо Рислинга…) — ответ исправлен
   вручную. Ещё 5 точек поставлены вручную на каталожные вина, которые SIFT не нашёл.
5. Не больше 3 кадров на одно вино, лишние 5 кадров убраны: 80 вин — по 1 кадру,
   16 — по 2, 6 — по 3.
6. Перцептивный хэш против друг друга и против исходников `store_shelves_v1`/`v2`,
   `real_photos_v4` и `real_photos_extra` — пересечений нет.

Правила — как в `store_shelves` после обновления 2026-09-27:

- **Редизайн = вне каталога.** Если оформление на полке отличается от каталожной
  карточки, кадр не брался: Шато Тамань брют с монограммой «C», Золотая Балка в новой
  круглой этикетке, Rouge/Blanc de Talu в рисованной этикетке, «Русское шампанское»
  Абрау вместо «Русского игристого», Alma Valley Cabernet Sauvignon в красной этикетке и т. п.
- Год урожая может отличаться от эталона, как в `real_photos_v4`.
- Несколько `accepted_slugs` через `;` — карточки одного вина, которые по фото не
  различить (две карточки Victor Dravigny брют, Brut d'Or Blanc de Blancs 12 % и 12,5 %,
  Авторское Пино Гри 2019 и 2023, Бастардо — Кефесия, Трио белое, Приват…). Таких кадров 10.
- Вина из серий с почти одинаковыми этикетками (`near_dup_group`): 39 кадров, 28 вин.

## Что важно знать

- **Фото чужие, права у авторов** (блогеры Дзена, посетители Яндекс Карт, авторы
  отзывов). Только для внутренней проверки, как `real_photos_v4`. Если репозиторий
  станет публичным, набор нужно убрать, в том числе из истории LFS.
- **Не обучать на нём**, иначе он перестанет быть независимой проверкой.
- Смещение отбора: кандидатов находил SIFT, поэтому крупных резких этикеток с
  детальным рисунком здесь больше, чем на настоящей полке; однотонные и мелкие
  этикетки представлены хуже.
- Кадры вырезаны из фото полок: ширина 288–1794 px, медиана 564 px — мельче снимка
  с телефона. Много фото 2019–2021 годов, JPEG пережат сайтами.
- Кадры одного исходного фото (`source`) и фото одной статьи (`page_url` в
  `sources.csv`) коррелированы: доверительные интервалы считайте по фото.
- Здесь только вина из каталога. Честный отказ проверяйте на наборах с винами вне
  каталога (`store_shelves_v1`/`v2`, `real_photos_v4`).

## Скачать, пересобрать, прогнать модель

```bash
git lfs pull --include="datasets/store_shelves_web/**"
python -m scripts.build_store_shelves --dataset store_shelves_web --prefix w --holdout
python infer_wine.py datasets/store_shelves_web/queries --top-k 5 \
    --output runs/inference/store_shelves_web_bottle_pipeline.json
```

Ответ верен, если top-1 входит в `accepted_slugs` своего кадра (любой из перечисленных
через `;`). Порядок строк `points.csv` задаёт номера `w-NNN`.
