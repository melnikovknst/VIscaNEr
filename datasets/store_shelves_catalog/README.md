# Магазинные полки: только вина из каталога

Отбор из `store_shelves_v1` и `store_shelves_v2`: кадры, на которых вино под центром
кадра есть в каталоге **в том же оформлении этикетки**. 209 кадров, 71 разное вино,
89 исходных фото полок.

Выброшено всё остальное:
- вина, которых нет в каталоге;
- редизайны: вино есть в каталоге, но этикетка на полке другая (Select Blanc, Эндемы,
  Abrau Collection, Velvet Season, Inkerman Winemaker's Selection, Портвейн Крымский
  и Меганом Солнечной Долины, Мускатное Фестивальное, Tamagne Терруар 2024, Адагум
  с птицей и с часами);
- розовый Портвейн Алушта — в каталоге только белый и красный;
- исключённые и нечитаемые кадры.

## Файлы

| Путь | Содержимое |
|---|---|
| `queries/*.jpg` | Кадры 3:4, копии из `store_shelves_v1/queries` (`s-NNN`) и `store_shelves_v2/queries` (`t-NNN`). |
| `labels.csv` | `query_id`, `image_path`, `accepted_slugs` (через `;` — карточки одного и того же вина), `note`, `dataset`, `source`, `x`, `y`, `group`. |

Делите на train/val/test по колонке `group` (исходное фото), а соседние снимки
одной полки держите вместе: кадры одного фото сильно пересекаются.

Набор пересобирается из `store_shelves_v1/labels.csv` и `store_shelves_v2/labels.csv`
по `training_use == catalog`.
