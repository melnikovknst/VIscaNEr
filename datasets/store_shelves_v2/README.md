# Магазинные полки v2: кадры и разметка

Второй заход в тот же винный магазин: 61 исходная фотография (`51.jpg` … `111.jpg`),
179 кадров с выбранной бутылкой в центре. Устроено так же, как `store_shelves_v1`,
номера кадров — `t-NNN`, чтобы не пересекаться с `s-NNN` из v1.

| Метка | Кадров |
|---|---:|
| вино из каталога (`status=ok`) | 83 (29 разных вин) |
| вина нет в каталоге (`notcat`, включая редизайны) | 93 |
| не определить (`unsure`: этикетка в сетке / загнута) | 3 |

Разметили GPT (фото 51–93) и Claude (фото 94–111); точки GPT проверены по кадрам.
Все каталожные соответствия сверены с эталонными фото каталога.

## Где что лежит

| Путь | Содержимое |
|---|---|
| `source/51.jpg` … `source/111.jpg` | Исходные фотографии полок. `sources.json` — sha256 каждого файла; `50.jpg` из той же выгрузки — дубль `store_shelves_v1/source/shelf-50.jpg` и исключён. |
| `points.csv` | Точка на этикетке и примерная ширина бутылки (проценты от размеров фото), статус, допустимые slugs, что написано на этикетке; `wine_key` — одно и то же вино на разных фото. |
| `review.json` | Пуст: спорные случаи решены (редизайны — вне каталога). |
| `labels.csv` | Одна строка на кадр, те же поля, что в v1, включая `training_use`. |
| `queries/t-001.jpg` … `queries/t-179.jpg` | Готовые кадры 3:4, целевая этикетка под центром кадра. |

`training_use`: `catalog` 83, `out_of_catalog` 93, `exclude` 3.

## Что важно знать

- В одном кадре обычно видны соседние бутылки; ответ — только бутылка под центром.
- Одинаковые бутылки в ряду отмечены один раз на фото, но одно вино встречается на
  нескольких фото подряд. Делите на train/val/test по исходному фото (а соседние
  снимки одной полки держите вместе), не по кадрам.
- Здесь много вин вне каталога: абхазские (Чегем, Апсны, Лыхны, Диоскурия, Псоу),
  Di Caspico special edition, Château Tamagne Терруар Цвайгельт и Reserve Saperavi 2022,
  Массандра Мерло/Каберне/Мадера. Это хороший материал для проверки отказа.
