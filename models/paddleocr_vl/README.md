# PaddleOCR-VL-1.6 weights

`PaddleOCR-VL-1.6.zip` is the portable, Git-LFS tracked model bundle used by
`ocr_reranker/run_label_ocr.py`. Unpack it from the repository root:

```bash
unzip -q models/paddleocr_vl/PaddleOCR-VL-1.6.zip -d models/paddleocr_vl
```

The unpacked `models/paddleocr_vl/PaddleOCR-VL-1.6/` directory is intentionally
Git-ignored. Checksums are recorded in `weights_sha256.json`.
