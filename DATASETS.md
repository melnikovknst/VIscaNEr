# Датасеты

Архивы лежат в `datasets/` и хранятся в Git LFS. Скачать:

```bash
git lfs install
git clone https://github.com/melnikovknst/VIscaNEr.git
# или только нужный архив в уже склонированном репозитории:
git lfs pull --include="datasets/real_photos_v4.zip"
```

| Архив | Размер | Что внутри |
|---|---|---|
| `real_photos_v4.zip` | 78 МБ | **Реальные фото для проверки сканера**: 918 снимков из Telegram — 906 вин из каталога (531 вино, 90+ виноделен, до 3 фото на вино) и 12 вин, которых в каталоге нет. Формат как у `eval.zip` кейсодержателя (`queries/`, `queries.tsv`), плюс `labels.csv` с ответами и `score.py` для top-1, честных отказов и задержки. |
| `wine-scanner_code-catalog.zip` | 332 МБ | Каталог на 2103 вина (`catalog.csv`), эталоны бутылок без фона и нормализованные 512 px, группы почти одинаковых этикеток, код нормализации и аугментации, манифест обучающей выборки, превью. |
| `wine-scanner_trainset.part1of2.zip`, `part2of2.zip` | 1.9 + 0.8 ГБ | **Синтетическая обучающая выборка**: 45 000 кадров (40 794 train, 4 206 val), 768 px. В четверти кадров — магазинная полка с соседними бутылками и ценниками. Винам из серий с похожими этикетками — по 31 кадру, остальным — 15–16. |
| `wine_labels_yolo_500.zip` | 58 МБ | **YOLO-разметка этикеток**: 500 случайных кадров синтетической выборки (400 train / 100 val), классы `label` (бокс с padding 10%) и `bottle`, 1 050 этикеток и 1 034 бутылки; 937 вырезок этикеток с тем же padding по папкам вин; `data.yaml` для ultralytics. Боксы точные — из генератора, каждый кадр проверен глазами. |

`wine-scanner_code-catalog.zip` и обе части выборки распаковываются в одну папку —
получается `wine-scanner/` (подробности в его `README.md`). `real_photos_v4.zip`
и `wine_labels_yolo_500.zip` распаковываются отдельно.

Контрольные суммы — в `datasets.sha256` (`sha256sum -c datasets.sha256` из корня репозитория).

## Важно

- **Фото в `real_photos_v4.zip` взяты из публичных Telegram-каналов, права у авторов постов.**
  Лицензия MIT этого репозитория на них не распространяется. Только для внутренней проверки;
  если репозиторий станет публичным, этот архив нужно убрать (в том числе из истории LFS).
- Реальные фото — в основном «лайфстайл» и съёмки виноделен, а не магазинные полки;
  Telegram сжимает их до ~1280 px. Цифры на них будут оптимистичнее, чем на приватном датасете.
- Синтетическая выборка воспроизводится скриптом `scripts/build_trainset.py --total 45000`
  из архива с кодом (~35 мин), если не хочется качать 2.7 ГБ.
